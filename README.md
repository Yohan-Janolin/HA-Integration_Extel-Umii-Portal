# 🚪 Extel Umii for Home Assistant

Based on the excellent work of [Jason Pretavoine](https://github.com/jasonpretavoine)  
Original repository: [https://github.com/jasonpretavoine/Extel-HomeAssistant](https://github.com/jasonpretavoine/Extel-HomeAssistant)

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/hacs/integration)
![Version](https://img.shields.io/badge/version-2.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

This custom integration lets you control **Extel** and **Avidsen** motorized gates that use the **Umii** app directly from Home Assistant.

---

## ✨ Features

* **Full Control**: Open, Close and Stop.
* **Pedestrian Opening**: A dedicated button for partial opening (`HALF-OPEN`).
* **State Feedback**: Real-time tracking of the gate state (Open/Closed).
* **Multi-Device**: Automatic discovery and setup of all gates linked to your account.
* **Connection error handling (v2.0.1)**: Automatically retries the connection on non-blocking errors (such as a DNS error).

> It is also required to use the **deviceToken** corresponding to your mobile application.
> In addition, the **User-Agent** expected by **Umii** includes a version number.  
> You therefore need to retrieve these 2 values by inspecting the requests sent by the iOS or Android app (see instructions below).

## 🚀 Installation

### Method 1: HACS (Recommended)

[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=Yohan-Janolin&repository=HA-Integration_Extel-Umii-Portal&category=integration)


### Method 2: Manual

1.  Download the `custom_components/extel_umii` folder.
2.  Copy it into the `custom_components` folder of your Home Assistant installation.
3.  **Restart Home Assistant**.

## ⚙️ Configuration

1.  Go to **Settings** > **Devices & services**.
2.  Click **Add integration** in the bottom right corner.
3.  Search for **Extel Portail**.
4.  Enter your Umii credentials (Email, Password).
5.  Follow the procedure below to get your deviceToken and User-Agent.

>     On iOS (iPhone)
>
>    The easiest way is to use the Proxyman app for iOS (free on the App Store).
>
>    1. Setting up Proxyman
>
>        Install Proxyman – HTTPS Capture from the App Store.  
>        Open the app and enable interception. iOS will ask you to allow a VPN configuration – accept it.  
>        Follow the in-app instructions to download and install the Proxyman certificate (via Safari at http://proxy.man/ssl).  
>        Crucial step: go to **Settings** → **General** → **About** → **Certificate Trust Settings** and turn on the switch for the Proxyman certificate.  
>        Without this step, HTTPS traffic will not be decrypted.  
>
>    2. Capturing the request
>
>       In Proxyman, start capturing.  
>       Fully close the Umii app (don't just send it to the background), then reopen it.  
>       Log out and log back in to Umii to force a new login request.  
>       In Proxyman, look for the request POST https://umii.avidsen.one/services/dain/login.  
>   
>    3. Extracting the values
>
>       User-Agent (UA): in the Headers of this request, copy the full value of the User-Agent field. It looks like: Umii/106 CFNetwork/3896.100.1.2.1 Darwin/27.0.0.  
>       Device Token: in the Body of the same request, copy the value of the deviceToken field. It is a long string (usually starting with letters and digits, and containing a `:`).  
>       ⚠️ Important: don't forget to disable the Proxyman VPN and remove the certificate once you're done, to avoid any security risk.  


>    📱 On Android
>   
>    **COMING SOON – NO ANDROID DEVICE AT HAND** 

6.  Select your gate from the list.
